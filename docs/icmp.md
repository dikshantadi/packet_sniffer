## Internet Control Message Protocol (ICMP)

After IPv4, the next protocol we encounter can be many different things. In our packet analyzer, one of them is ICMP.

ICMP stands for Internet Control Message Protocol. It is a network-layer (ahem layer 3) protocol used to send control and error information between network devices.

You may have used ICMP before unknowingly, where you ask?

When you run 

`` Ping "ip address "``

eg: ``ping 1.1.1.1 ``

your computer sends an ICMP message to 1.1.1.1 asking whether it is reachable. If the destination is able to respond, it sends an ICMP reply back.

### ICMP in IPv4

ICMP is carried inside an IPv4 packet.

Remember that the IPv4 header contains a Protocol field. This field tells us what protocol is contained inside the IPv4 payload.

For ICMP:

Protocol = 1 → ICMP

### What does ICMP do?
For starter ICMP is not used to carry normal application data like TCP or UDP. Instead, it is mainly used for control messages, diagnostics, and error reporting.

So you can think of ICMP as a way for network devices to communicate information about what is happening to packets.

### ICMP Header 

```
ICMP Header

┌──────────┬──────────┬──────────────────────┐ 
│ Type     │ Code     │ Checksum              │ 
│ 1 byte   │ 1 byte   │ 2 bytes               │ 
├──────────┴──────────┴────────────────────── ┤ 
│ Message-specific fields                     │ 
└─────────────────────────────────────────────┘

```
The first four bytes contain:

1. Type — 1 byte
2. Code — 1 byte
3. Checksum — 2 bytes

The fields after these depend on the type of ICMP message.

### Type

The Type field tells us what kind of ICMP message we are looking at.

Some common ICMP types are 

```
Type 0 → Echo Reply 
Type 3 → Destination Unreachable 
Type 5 → Redirect 
Type 8 → Echo Request 
Type 11 → Time Exceeded
```
For example:

Type = 8, means that the message is an Echo Request.

And:

Type = 0, means that it is an Echo Reply.

These are the messages used by ``ping``.

### Code 

The Code field provides more specific information about the message type.

Type → What happened?

Code → More specifically, what happened?

For Echo Request and Echo Reply, the Code is normally:

``Code = 0``

Some other ICMP message types have multiple possible Code values that provide additional information about the error or event.

### Checksum 

The ICMP Checksum is used to detect errors in the ICMP message.

### Echo Request and Echo Reply

Let's look at the ICMP messages generated by ``ping.``

When our computer sends a ping, it sends an Echo Request:
```
Type = 8
Code = 0
```
The destination can respond with an Echo Reply:
```
Type = 0
Code = 0
```
The structure looks roughly like this: 

```
ICMP Echo Message 

┌──────────┬──────────┬──────────────────────┐ 
│ Type     │ Code     │ Checksum             │ 
├──────────┴──────────┴──────────────────────┤ 
│ Identifier                                 │ 
├────────────────────────────────────────────┤ 
│ Sequence Number                            │ 
├────────────────────────────────────────────┤ 
│ Data                                       │ 
│                                            │
└────────────────────────────────────────────┘
```
The fields after the checksum are specific to Echo Request and Echo Reply messages.

### Identifier 
The Identifier helps associate an Echo Reply with the Echo Request that generated it.

```
Echo Request Identifier = 45637 
Echo Reply Identifier = 45637
```
The matching identifier helps the sender determine which request the reply belongs to.

### Sequence Number 
The Sequence Number helps distinguish between multiple Echo Requests.

```
Echo Request 
Identifier = 45637 
Sequence Number = 25 

Echo Request 
Identifier = 45637 
Sequence Number = 26 

Echo Request 
Identifier = 45637 
Sequence Number = 27
```
The replies can contain the corresponding sequence numbers, allowing the sender to match each reply to its request.

Let's break down what happened.

The Ethernet header contains:

EtherType = 0x0800, which tells us that the payload contains an IPv4 packet.

IPv4 then contains:

Protocol = 1, which tells our parser that the IPv4 payload contains ICMP.

Our parser then reads the ICMP header:

Type = 0
Code = 0

Type 0 means Echo Reply.

So our computer is receiving a ping request from: 1.1.1.1

### ICMPv6
IPv6 uses ICMPv6 instead of the original ICMP protocol.

IPv6 identifies ICMPv6 using:

Next Header = 58

ICMPv6 is more than just an IPv6 version of ICMP. It is also an important part of IPv6 itself and is used for functions such as Neighbor Discovery Protocol (NDP).

We'll cover ICMPv6 separately when we expand our IPv6 parser.
